# 用户流程 · 0.3
## 主流程
进入工作台 → 填写 / 选择 Campaign Brief → 提交 → 规则解析 → RAG 检索 → 市场、竞品、复盘并行分析 → 核查来源 → 人工选择方向并补充意见 → 生成 Campaign Brief → 规则质检 → 查看复盘与实验计划 → 制作广告 → 选择参考素材或提示词路径 → 编辑创意方案与分镜 → 选择模型与确认 → 生成图片 → 客户验收 → 录入模拟投放 → 版本复盘 → 新一轮创意。

## 页面状态与触发
| 状态 | 用户可执行 | 系统行为 |
|---|---|---|
| 尚未开始 | 修改表单、换示例、清空 | 本地保存草稿 |
| researching | 查看各标签页、取消 | 解析后并行研究，SSE 更新 |
| awaiting_approval | 检查证据、选方向、修改意见、确认或取消 | 任务持久化暂停，不生成最终稿 |
| generating | 查看阶段状态、取消 | 整合批准方向、历史案例与复盘，质检 |
| completed | 复制、下载、查看历史、基于当前输入新建、删除 | 保留讨论稿与确认记录 |
| failed / cancelled / interrupted | 查看已完成结果、重新新建、删除 | 不自动覆盖原任务 |

## 输入与历史
创建后当前表单锁定，避免新输入与旧结论混在一起。新建任务保留当前 Brief；清空按钮创建空白草稿。历史列表显示产品名和状态，重新打开可查看保存内容。刷新恢复最近任务，待确认任务可跨服务重启继续；运行中断需新建任务。

## 引用与实验
点击结论旁的 source ID → 打开摘要、相关性、原始 JSON → 关闭返回原焦点。无证据时显示覆盖缺口。
复盘 → 查看原始计数与计算值 → 查看未启动实验计划 → 可在独立沙盘切换场景。沙盘结果不改变已保存任务，正式改变数据要新建任务。

## 异常与控制
- 必填空白或非法数值：前后端拒绝，不消耗模型调用。
- DeepSeek 失败：该阶段降级并展示标识，流程继续。
- MCP 失败：任务标记失败，保留已完成的证据与记录。
- 网络断开：SSE 自动重连，5 秒轮询兜底；客户端不模拟完成。
- 取消：终止正在运行的子任务，关闭 MCP 子进程；不再生成后续内容。
- 重复确认：409 提示刷新状态；未勾选声明不能提交。
- 未完成导出：409；完成后复制和下载的是同一份 Markdown。

任何流程均不包含真实发布、预算调整或广告账户授权。

## 广告服务状态与操作
| 当前状态 | 下一步 | 规则 |
|---|---|---|
| 素材 / 需求 | 生成创意方案 | 素材路径必须选中匹配参考；提示词路径不需要素材 |
| 待确认方案 | 编辑内容、选择模型、复制提示词 | 草稿在浏览器保存；需求快照锁定 |
| 内容已确认 | 生成图片 | 外部模型另需数据发送与费用授权；缺少密钥不可调用 |
| 生成中 | 查看、刷新状态、切换工作台 | 状态刷新不会重新生成，不接受同页重复提交 |
| 生成失败 / 中断 | 查看错误、手动返回编辑 | 不自动切 Mock，不自动重试计费 |
| 生成成功 | 下载 PNG / ZIP，勾选验收 | 下载的是当前生成内容快照；未确认标为草稿 |
| 已确认交付 | 模拟投放复盘 | 并未真实投放；绑定当前 job ID |
| 已复盘 | 查看数据、填写改版意见、创建 V2 | 已提交复盘不覆盖，保留父版与客户反馈 |
| 下一版方案 | 再次编辑、确认、生成 | 不因复盘完成就自动调用付费模型 |

可以从顶部“广告创意交付”直接接收独立客户需求；从 Brief 点击“制作广告”则继承已确认策略。关联输入不能与来源不一致，需要改变核心需求时取消关联后新建。历史交付可回看独立广告与状态，下一版侧栏可以回到父版本。

素材搜索无结果时明确提示并提供提示词路径。外部生成请求先记录 request_id，丢失网络响应后刷新优先恢复相同历史请求；不会仅因页面刷新自动发起收费生成。
