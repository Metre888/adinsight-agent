# 完整体验路径

版本：0.3。先按根目录 README 启动前后端；无需配置密钥。

## 从研究到广告
| 步骤 | 操作 | 可观察结果 |
|---|---|---|
| 1 | 使用 LumaSnap 示例，检查产品、市场与目标 | 合成需求完整，可以修改后再提交 |
| 2 | 点击“开始研究” | 解析后市场、竞品、复盘并行，状态来自实际后端事件 |
| 3 | 打开执行记录与知识来源 | 查看 MCP 参数、结果、耗时及来源原文 |
| 4 | 选择方向，填写修改意见并确认数据声明 | 人工确认前没有最终 Brief，意见保留在任务中 |
| 5 | 确认并生成 Brief | 结构化讨论稿、指标、引用和待核验事项，可复制或导出 |
| 6 | 点击“制作广告” | 已确认 Brief 的快照传入创意需求 |
| 7 | 选择合成素材，生成创意方案 | 文案、CTA、提示词与分镜可编辑，来源可回看 |
| 8 | 修改标题，确认内容，选择本地排版并生成 | 真实产生 PNG，不执行自由画面提示词，不调用付费服务 |
| 9 | 检查后确认交付，下载 ZIP | 包含图片、Brief、提示词、分镜与交付说明 |
| 10 | 提交模拟投放计数和客户反馈 | MCP 确定性计算指标，复盘绑定已确认广告版本 |
| 11 | 点击“带入复盘，创建 V2” | 保留父版本与反馈，新方案再次确认后才生成 |

## 独立客户需求
进入广告创意交付，新建需求；不关联研究任务，填写产品与市场。在“从提示词创作”路径生成方案，不选择历史素材，系统不会捏造素材引用。

客户可以编辑文案、提示词与约束，选择已配置图像服务。外部调用前需授权数据发送及可能费用；无密钥时使用本地排版继续体验。

## 边界检查
1. 更换到知识库未覆盖的地区，查看无证据提示，而非混入无关国家的材料。
2. 研究完成后不确认，刷新页面，检查待确认状态可以恢复。
3. 复盘沙盘选择无样本，分母为零的指标应显示不可计算。
4. 选择未配置图片模型，查看配置与费用限制，不应伪装调用成功。
5. 已确认广告复盘后创建下一版，旧交付必须保留，不被新文案覆盖。

无密钥时文本来自规则模板、图片来自本地排版；MCP、检索、并行编排、审批、状态保存、指标、文件和导出仍真实执行。Demo 不自动发布广告，不提供真实投放效果保证。
